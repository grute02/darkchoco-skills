# 북마클릿

브라우저 주소 칸에 넣어 쓰는 수집 도구다. 사람이 연 페이지에서 누른다.
스킬이 부르지 않는다. `skills/darkweb-verify-ko/tools/` 의 파이썬과 별개다.

## 무엇이 있나

| 파일 | 어디에 | 무엇 |
|---|---|---|
| `forum_kit_v2.5.bookmarklet.txt` | MyBB·XenForo 포럼 | 게시판 지도, 글 목록, 본문, 구조 진단 |
| `qilin_kit.js` | 킬린 랜섬웨어 유출 사이트 | 피해자 목록, 증거 사진 수, 파일 목록 |
| `index_kit.js` | 노출된 디렉터리 인덱스 | 폴더만 걸어다니며 경로 목록. 안 열어본 폴더와 걸리는 시간을 적는다 |
| `probe_generic.js` | 구조를 모르는 사이트 | DOM 진단. 무엇을 긁을지 정할 때 |

**`forum_kit v2.5` 는 읽는 소스가 없다.** 빌드 결과 한 줄만 남아 있어 고치려면 압축본을 직접 손봐야 한다.

## 최소화

넷 다 화면 오른쪽 아래로 접힌다. `최소화` 를 누르면 상자가 줄고 **상태줄과 중단 버튼만 남는다.**
걸어다니는 중에 아래 페이지를 보면서 진행 상황을 확인할 때 쓴다. `펼치기` 로 되돌린다.

`forum_kit` 은 읽는 소스가 없어서 압축본 뒤에 조각을 붙여 넣었다.
그 조각은 아직 최소화가 없는 상자 중 마지막 것을 찾아 버튼을 단다.

## 어떻게 쓰나

`.bookmarklet.txt` 안의 한 줄을 북마크 주소로 넣는다. 대상 페이지에서 그 북마크를 누른다.

`.js` 를 고쳤으면 반드시 다시 만든다.

    python bookmarklets/build_bookmarklet.py

`node --check` 를 통과해야만 txt 를 쓴다. 실패하면 옛 txt 를 그대로 둔다.

## 고칠 때 지킬 것

- **`//` 주석을 쓰지 마라.** 한 줄로 합치면 뒤가 통째로 주석이 된다. `/* */` 를 쓴다.
  줄 맨 앞이든 줄 끝이든 빌더가 막는다
- 요청 간격 2.5~5초를 줄이지 마라. 계정과 회선을 셋이 공유한다
- 403, 429, 503, Cloudflare 문구면 즉시 중단한다
- **파일을 내려받는 기능을 넣지 마라.** 팀 규칙이다
- 60,000자를 넘으면 주소 칸에서 잘릴 수 있다
