# ⑦ 결과 검토

검토자가 하는 단계다. 아래는 검토 질문을 뽑는 보조용이다.

**⑥ 출력을 위에서부터 읽으면서 해당 단계 표를 본다.**
어느 단계에서 생긴 문제인지 알아야 어디를 다시 돌릴지 정해진다.

## ③ 사전 확인에서 생기는 것

| 확인 | 조치 |
|---|---|
| **질의 다섯을 다 돌았는가** | 특히 3-1 핸들 단독. 안 돌았으면 다시 |
| **식별자를 한 질의에 섞었는가** | 나눠서 다시 돌린다 |
| **채택한 문서에 대상 문자열이 있는가** | 없으면 버린다 |
| **팀 DB를 먼저 봤는가** | 안 봤으면 ③부터 다시. 중복 채번이 생긴다 |

## ④ 마스킹에서 생기는 것

| 확인 | 조치 |
|---|---|
| 샘플 실제 값이 남았는가 | 한 글자라도 남으면 다시 돌린다 |
| **파일명 개인정보가 그대로 남았는가** | 가려서 다시 낸다 |

## ⑤ 재료 합치기에서 생기는 것

| 확인 | 조치 |
|---|---|
| **출처에 대상 문자열이 있는가** | 최종 출처 목록까지 본다. 없으면 뺀다 |
| **후속 링크 큐를 판정 근거로 썼는가** | 뺀다. 다음 조사의 입력이다 |

## ⑥ 판정 근거에서 생기는 것

| 확인 | 조치 |
|---|---|
| 계산이 재료와 맞는가 | 직접 검산 |
| 적신호 하나로 결론을 냈는가 | 재검토 |
| **C 계상 근거가 재현 가능한가** | 보조 질문 5번. 재현 못 하면 계상 보류 |
| **위험도가 진위에 끌려갔는가** | 미확인인데 위험도가 낮게 나왔으면 다시 본다 |
| **위험도 총점이 붙었는가** | 항목별로 되돌린다 |
| 툴킷이 판정을 단정했는가 | 참고만 하고 ⑧에서 직접 매김 |
| 툴킷 5단계를 그대로 옮겼는가 | 과거 자료 재포장은 진위가 아니라 신규성 재유포다 |
| **권고 세 갈래가 있는가** | 없으면 조사 메모다. ⑥에 8번으로 |
| 한계가 비어 있는가 | 대부분 있어야 정상. 비었으면 재검토 |

## 어느 단계에서든 생기는 것

| 확인 | 조치 |
|---|---|
| 재료에 없는 정보를 채웠는가 | 환각. 해당 줄 폐기 |
| **못 봄과 없음을 구분했는가** | 못 본 것을 없음으로 적었으면 고친다 |
